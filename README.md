# MagerCam: телефон как веб-камера (аналог DroidCam)

Android-телефон превращается в камеру и микрофон для компьютера по Wi-Fi или USB.

| Часть | Где | Что делает |
|-------|-----|------------|
| Android-приложение | `android/` → `MagerCam.apk` | Камера (Camera2) → H.264/H.265 (аппаратный MediaCodec) + звук 48 кГц → сеть |
| Программа для Windows | `windows/` → `MagerCam.exe` | Принимает видео с телефона и показывает его как веб-камеру **«MagerCam»** в Zoom, Discord, Teams, Telegram, браузере |
| Плагин OBS | `obs-plugin/` | Источник «MagerCam (телефон)» прямо в OBS: видео + звук, управление камерой телефона |
| Веб-панель | встроена в приложение | `http://IP:4848/`: просмотр и управление из браузера, MJPEG для любых программ |

Протокол описан в [`docs/PROTOCOL.md`](docs/PROTOCOL.md).

## Установка

Готовые файлы лежат в [Releases](../../releases): `MagerCam.apk`, `MagerCam-Windows.zip`, `MagerCam-OBS-plugin.zip`.

### 1. Приложение на телефон

Скопируйте `MagerCam.apk` на телефон и откройте его (Android 8.0+). Разрешите камеру, микрофон и уведомления.
Если телефон подключён по USB с включённой «Отладкой по USB», можно запустить `install-apk.bat`.

### 2а. Программа для Windows (веб-камера для Zoom/Discord)

1. Распакуйте `MagerCam-Windows.zip` и запустите **`install-windows.bat`** (он попросит права администратора).
   Программа ставится в `C:\Program Files\MagerCam`, появляются ярлыки в «Пуске» и на рабочем столе.
   Для режима USB установщик сам скачает `adb` с официального сайта Google (Android platform-tools).
2. Откройте MagerCam, выберите телефон и нажмите «Подключить»:
   - **Wi-Fi**: телефон находится кнопкой «Найти», или впишите IP с экрана телефона;
   - **USB**: переключатель «USB». Программа сама найдёт adb и сделает `adb forward`.
3. В Zoom, Discord, Teams или браузере выберите камеру **MagerCam**.

Быстрее всего подключиться по QR: нажмите в программе «QR-сопряжение…» и отсканируйте код кнопкой **QR** в приложении
(или обычной камерой телефона). Телефон сам передаст свой адрес и код доступа, вводить ничего не нужно.
Установщик открывает для этого входящие TCP-порты 4850–4859 в частных сетях.

Что умеет программа:
- **Виртуальная камера «MagerCam»** без отдельного драйвера. Используется встроенный в **Windows 11** механизм виртуальных камер (Media Foundation, `MFCreateVirtualCamera`). Отдаёт NV12 1920×1080, 1280×720, 960×540 и 640×360 при 30/60 к/с. Пока телефон не подключён, показывает заставку «Нет сигнала».
- Камера существует, **пока открыта программа**. Поэтому есть галочки **«Запускать вместе с Windows»** (стартует свёрнутой) и **«Сворачивать в трей»**: крестик и сворачивание прячут окно к часам, а не закрывают его. Выход через меню значка в трее.
- **Выбор объектива**: в списке все камеры телефона. Это фронтальная и задняя, а на телефонах, которые это поддерживают, ещё и отдельные широкоугольный и телевик.
- Разрешение, к/с и битрейт с телефона, фонарик, автофокус, зум, экспозиция.
- Поворот 0/90/180/270, зеркало, режим «Без полей (обрезать)» для вертикального телефона.
- **Звук с телефона** выводится на выбранное устройство. Чтобы он стал *микрофоном* в Zoom/Discord, поставьте бесплатный [VB-CABLE](https://vb-audio.com/Cable/), выберите в MagerCam «CABLE Input», а в Zoom/Discord микрофон «CABLE Output».
- Предпросмотр в окне, одна копия программы на каждую камеру (повторный запуск разворачивает уже открытую).
- **До четырёх телефонов сразу**: кнопка «Ещё телефон…» открывает второе окно, и в системе появляется камера **«MagerCam 2»** (до «MagerCam 4»). У каждой свои настройки и свой автозапуск.
- **H.265**: галочка «H.265 (меньше трафика)» вдвое снижает поток при том же качестве. Нужны кодер H.265 на телефоне и «Расширения для видео HEVC» из Microsoft Store (или драйвер видеокарты с HEVC) на ПК; без них программа сама остаётся на H.264.
- **Цвет**: яркость, контраст, насыщенность, теплота, свои 3D-LUT в формате `.cube` и **режим документа**, который вытягивает белый лист и делает текст резче. Всё применяется к кадру до виртуальной камеры, поэтому видно в любой программе.
- **Функции телефона** прямо из программы: профили «Звонок / Стрим / Документ», автокадрирование по лицу, размытие или замена фона (картинку можно выбрать на ПК), блокировка экспозиции и баланса белого, адаптивный битрейт, защита от перегрева, запись видео на телефон.
- **Код доступа** с телефона вводится один раз и хранится в настройках. По USB он не нужен.
- По USB программа сама запускает приложение на телефоне, если оно закрыто.

Удаление: `uninstall-windows.bat` (или `install.ps1 -Uninstall` из папки программы).

> Windows 10 не поддерживает виртуальные камеры Media Foundation. Там используйте OBS: плагин MagerCam + кнопку «Запустить виртуальную камеру» в OBS.

### 2б. Плагин OBS

1. Распакуйте `MagerCam-OBS-plugin.zip` и запустите `install-obs-plugin.bat`. Плагин копируется в `C:\ProgramData\obs-studio\plugins\magercam`. **Перезапустите OBS.**
2. Источники → `+` → **MagerCam (телефон)** → выберите телефон из «Найденные телефоны» или впишите IP. Для USB выберите «Подключение» → «USB (через ADB)».
3. Звук с микрофона телефона идёт в OBS вместе с видео, синхронно. Отключается галочкой «Передавать звук с микрофона телефона».
4. Если на телефоне включён код доступа, впишите его в поле «Код доступа».

Удаление: `uninstall-obs-plugin.bat`.

Телефон и ПК должны быть в одной сети (для Wi-Fi).
Чтобы подключаться через интернет (с дачи, из другого офиса), поставьте [Tailscale](https://tailscale.com/) на телефон и ПК
и впишите в MagerCam адрес телефона вида `100.x.y.z` (он виден на экране приложения) или подключитесь по QR — телефон передаст все свои адреса.
Код доступа при этом обязателен. Если автопоиск ничего не находит, впишите IP вручную: скорее всего, UDP-бродкаст блокирует брандмауэр или роутер.

## Возможности

**Приложение**
- Любая камера телефона (задняя / фронтальная / широкоугольная / телевик), разрешение до 4K, 15–60 к/с, битрейт 1–50 Мбит/с
- Звук с микрофона (источник: видеокамера / микрофон / голос с шумоподавлением / без обработки), кнопка mute
- Фонарик, зум (включая 0.5x на поддерживающих телефонах), экспозиция, фокус (непрерывный / по касанию / бесконечность / макро / ручной)
- Баланс белого, блокировки AE/AWB, антимерцание 50/60 Гц, стабилизация (EIS + OIS)
- Работа в фоне и при выключенном экране (foreground service, wake/wifi lock), кнопка затемнения 🌙
- Камера включается только когда есть зритель: превью, OBS, программа Windows или браузер
- Автоповорот: картинка ровная в любом положении телефона (или фиксированная ориентация)
- При перегрузке сети кадры сбрасываются до ближайшего ключевого, чтобы задержка не накапливалась
- **Адаптивный битрейт**: на слабом Wi-Fi картинка становится мягче, но не замирает
- **H.265** для клиентов, которые его умеют: вдвое меньше трафика
- **Код доступа** из 6 цифр (включён по умолчанию) и сопряжение по QR. После 10 неверных попыток адрес блокируется на минуту
- **Профили** «Звонок», «Стрим», «Документ»: разрешение, к/с, битрейт, объектив, стабилизация и звук одним нажатием
- **Автокадрирование**: кадр плавно следует за лицом, как Center Stage
- **Размытие и замена фона** на телефоне (модель сегментации работает прямо на телефоне, без интернета)
- **Запись** в MP4 на сам телефон (`Movies/MagerCam`) параллельно с трансляцией, в полном качестве
- **Защита от перегрева**: при горячей батарее снижает к/с и битрейт, потом возвращает

**Плагин OBS**
- Wi-Fi с автопоиском (UDP) или USB через ADB (выбирает устройство, где запущен MagerCam)
- Видео H.264/H.265 (программное или аппаратное D3D11-декодирование) + звук, синхронизированные по общим меткам времени
- Код доступа, профили, фон, автокадрирование, блокировка экспозиции и кнопка записи на телефон
- Режим минимальной задержки, автопереподключение, отключение при скрытии источника
- Поворот 0/90/180/270/авто, зеркало
- Управление телефоном прямо из свойств источника: объектив, фонарик, фокус, зум, экспозиция, ББ, антимерцание, стабилизация

**Браузер / другие программы**
- `http://IP:4848/`: веб-панель: просмотр, все настройки, профили, загрузка картинки для фона, запись,
  **детектор движения** (сравнивает кадры прямо в браузере, звук, уведомление и галерея снимков — телефон как камера наблюдения)
- `http://IP:4848/video`: MJPEG (OBS «Медиаисточник», VLC, любые IP-cam программы)
- `http://IP:4848/shot.jpg`: снимок

## Как устроена программа для Windows

```
телефон ──H.264+звук──▶ MagerCam.exe ──NV12──▶ общая память ──▶ magercam-vcam.dll ──▶ Frame Server ──▶ Zoom/Discord
          (Wi-Fi/USB)   декодер MF,      Global\MagerCamVirtualCamera   (COM media source,
                        WASAPI-звук                                      служба Windows)
```

- `windows/client/`: программа на C/Win32. Сеть и автопоиск, декодер H.264/H.265 из Media Foundation, цветокоррекция и LUT, QR-сопряжение, вывод звука через WASAPI, UI и трей. Регистрирует виртуальную камеру через `MFCreateVirtualCamera` на время работы. С ключом `--slot 1..3` работает как вторая–четвёртая камера.
- `windows/vcam/`: media source (C++/COM), который служба камер Windows (Frame Server) загружает в свой процесс. Читает кадры из общей памяти и отдаёт их приложениям с точным темпом 30/60 к/с.
- `windows/common/`: общий формат разделяемой памяти (seqlock, NV12), масштабирование/поворот NV12, генератор QR-кодов.
- `windows/install.ps1`: регистрация COM-классов всех четырёх камер в HKLM (служба не видит HKCU), правило брандмауэра для QR-сопряжения, ярлыки, скачивание adb, удаление.

## Сборка

Всё собирается **llvm-mingw** (MSVC не нужен) из Git Bash. Зависимости кладутся в `C:\mc-build` (переопределяется `MC_DEPS`):

```sh
sh obs-plugin/setup-deps.sh    # llvm-mingw, заголовки libobs/FFmpeg, import-библиотеки из установленного OBS
sh obs-plugin/build.sh         # → obs-plugin/build/magercam.dll
sh windows/build.sh            # → windows/build/MagerCam.exe, magercam-vcam.dll и dist/windows/
cd android && ./gradlew assembleRelease   # APK (JDK 17 + Android SDK 34)
```

Для отладки: `node tools/fake-phone.js [порт] [--key 123456]` эмулирует телефон (тестовая картинка, тон 440 Гц, несколько объективов, H.264 и H.265 через ffmpeg, код доступа) по протоколу MagerCam. `node tools/obs-test.js ws://127.0.0.1:4455 <пароль>` автоматически тестирует источник через obs-websocket.

## Структура

```
android/       приложение (Kotlin, Camera2, MediaCodec, встроенный HTTP-сервер)
obs-plugin/    плагин OBS (C, libobs + FFmpeg из OBS)
windows/       программа и виртуальная камера для Windows 11
docs/          протокол
tools/         эмулятор телефона и автотесты
*.bat          установка/удаление для пользователей
```

## Лицензия

[GPL-2.0](LICENSE). Плагин OBS собирается с libobs, которая распространяется под GPL-2.0, поэтому весь проект выпущен под той же лицензией.

Приложение использует модель [MediaPipe](https://github.com/google-ai-edge/mediapipe) `selfie_segmenter` (Apache 2.0) для отделения человека от фона.
В файле `android/app/src/main/assets/selfie_segmenter.tflite` нестандартная операция MediaPipe `Convolution2DTransposeBias` заменена на встроенную `TRANSPOSE_CONV`, чтобы модель работала в обычном TensorFlow Lite; веса не менялись.
